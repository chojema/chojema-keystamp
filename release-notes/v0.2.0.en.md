# Chojema KeyStamp v0.2.0

[한국어](v0.2.0.md) | English

This version was withdrawn. Please use [v0.2.1](v0.2.1.en.md).

This version creates images and animations of the whole keyboard.

## New features

- **Full keyboard:** Under `Keyboard`, set `Show` to `Full` to see the whole keyboard. You can save or copy it as is.
- **Highlight chosen keys:** Color the keys you entered and quieten the rest. You can turn this off.
- **Windows or Mac keys:** Windows keys are the default, and you can switch to Mac keys.
- **Number pad:** Choose whether to include it. Enter its keys as `Num1`, `NumEnter`, and so on.
- **Animation:** Save the chosen keys being pressed on the full keyboard as HTML, GIF, or APNG.

## Changes

- The app has a new icon, which the installer also uses.
- The surrounding keys checkbox is now part of `Show: Keys / Nearby / Full`.
- Copying a full keyboard image now fits it within 1920 by 1080 pixels.
- PNG images are limited to 8192 pixels on the long side, and GIF and APNG to 1280 pixels wide.

## Install

Download and run `Chojema-KeyStamp_0.2.0_x64-setup.exe`. It is for 64-bit Windows 10 or later.

## Known limitations

- This version has no macOS installer.
- The installer is not code signed, so Windows SmartScreen may show a warning.
- The JIS layout is not supported. The ISO Enter key is drawn as a rectangle.
- For speed, keys you did not choose are drawn with slightly simpler 3D shapes on the full keyboard.
- GIF has no partial transparency. Use APNG for transparent backgrounds.
