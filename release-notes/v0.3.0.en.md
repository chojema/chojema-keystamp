# Chojema KeyStamp v0.3.0

[한국어](v0.3.0.md) | English

Adds a 2D full keyboard view and an About menu.

## Changes

- **2D full keyboard:** Under Keyboard, choose Full, then set Appearance to 2D for a crisp, flat keyboard. Switch between 2D and the existing 3D view. The appearance setting is remembered between sessions.
- **2D image export:** Copy and save preserve Windows or Mac keys, ANSI, ISO, or Korean layouts, the number pad, Hangul letters, selected-key highlights, colors, and background settings. Color changes indicate presses in 2D animations.
- **About menu:** About in the top bar shows author information and links to the [GitHub repository](https://github.com/chojema/chojema-keystamp) and [Chojema App Park](https://chojema.github.io/AppPark/). Links open in the default browser.

## Install

Download and run `Chojema-KeyStamp_0.3.0_x64-setup.exe`. It is for 64-bit Windows 10 or later.

## Validation

- All 48 automated tests and the Windows x64 build passed.
- Browser previews verified 2D view switching, settings persistence, PNG and SVG downloads, and clipboard copying.
- About checks covered Korean and English labels, closing with the button and Escape, link destinations, narrow screens, and the dark theme.

## Known limitations

- This version has no macOS installer.
- The installer is not code signed, so Windows SmartScreen may show a warning.
- Opening the default browser from About links and the native file-save dialog were not directly retested in the Windows app for this version.
- The JIS layout is not supported. The ISO Enter key is drawn as a rectangle.
- GIF has no partial transparency. Use APNG for transparent backgrounds.
