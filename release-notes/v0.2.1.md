# Chojema KeyStamp v0.2.1

한국어 | [English](v0.2.1.en.md)

v0.2.0을 대체하는 버전입니다. v0.2.0을 쓰고 있다면 이 버전으로 업데이트하세요.

## 바뀐 점

- 3D 이미지와 2D 이미지의 Win 키를 Windows 로고 대신 `Win` 글자로 표시합니다.

복사용 텍스트의 Win 키 표기(`⊞+[E]`)와 다른 기능은 그대로입니다. 키보드 전체 보기 등 v0.2.0의 기능은 [v0.2.0 릴리스 노트](v0.2.0.md)를 참고하세요.

## 설치

`Chojema-KeyStamp_0.2.1_x64-setup.exe`를 내려받아 실행하세요. Windows 10 이상의 64비트 환경용입니다.

## 알려진 제한

- macOS용 설치 파일은 이번 버전에 없습니다.
- 코드 서명이 되어 있지 않아 Windows SmartScreen 경고가 나올 수 있습니다.
- JIS 배열은 지원하지 않습니다. ISO Enter 키는 직사각형으로 그립니다.
- GIF는 반투명을 표현하지 못합니다. 투명 배경에는 APNG를 쓰세요.
