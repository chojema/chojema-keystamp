# Chojema KeyStamp v0.1.0

[한국어](v0.1.0.md) | English

This is the first public version.

## What you can do

- Create 3D keycap images of single keys and combinations such as `Ctrl + Shift + Z`
- Change the angle with the top, 30°, 45°, and 60° presets, or by dragging
- View Windows and Mac images together, or just one of them
- Save SVG and PNG files, and copy to the clipboard
- Copy text results such as `[Ctrl]+[C]` and `⌃C`
- Copy and save 2D keycap PNGs that fit inside a sentence
- Show surrounding keys with blurred edges (ANSI, ISO, and Korean layouts)
- Show Latin and Hangul letters together
- Save key press animations as HTML, GIF, or APNG

## Install

Download and run `Chojema-KeyStamp_0.1.0_x64-setup.exe`. It is for 64-bit Windows 10 or later.

## Known limitations

- This version has no macOS installer.
- The installer is not code signed, so Windows SmartScreen may show a warning.
- Keys that the operating system handles first, such as `Ctrl + Alt + Del`, can't be captured by pressing them. Type them in the input field instead.
- GIF has no partial transparency. Use APNG for transparent backgrounds.
- The numeric keypad and JIS layout are not supported. The ISO Enter key is drawn as a rectangle.
- Pasted results may look different depending on the document app and font.
