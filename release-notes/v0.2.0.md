# Chojema KeyStamp v0.2.0

한국어 | [English](v0.2.0.en.md)

키보드 전체를 이미지와 애니메이션으로 만들 수 있는 버전입니다.

## 새 기능

- **키보드 전체:** `키보드` 영역의 `보기`에서 `전체`를 고르면 키보드 전체가 나옵니다. 그대로 저장하거나 복사할 수 있습니다.
- **지정한 키 강조:** 입력한 키에 색을 넣고 나머지는 흐리게 표시합니다. 끌 수도 있습니다.
- **자판 전환:** 기본은 Windows 자판이고 Mac 자판으로 바꿀 수 있습니다.
- **넘버패드:** 넘버패드 포함 여부를 고를 수 있습니다. `Num1`, `NumEnter`처럼 입력해 지정합니다.
- **애니메이션:** 키보드 전체 위에서 지정한 키가 눌리는 동작을 HTML, GIF, APNG로 저장합니다.

## 바뀐 점

- 새 앱 아이콘을 적용했습니다. 설치 파일에도 같은 아이콘이 나옵니다.
- 주변 키 체크박스를 `보기: 키만 / 주변 키 / 전체` 선택으로 합쳤습니다.
- 키보드 전체를 이미지로 복사하면 가로 1920px, 세로 1080px 안에 들어오도록 줄입니다.
- PNG는 긴 변을 8192px로, GIF와 APNG는 폭을 1280px로 제한합니다.

## 설치

`Chojema-KeyStamp_0.2.0_x64-setup.exe`를 내려받아 실행하세요. Windows 10 이상의 64비트 환경용입니다.

## 알려진 제한

- macOS용 설치 파일은 이번 버전에 없습니다.
- 코드 서명이 되어 있지 않아 Windows SmartScreen 경고가 나올 수 있습니다.
- JIS 배열은 지원하지 않습니다. ISO Enter 키는 직사각형으로 그립니다.
- 키보드 전체를 그릴 때는 속도를 위해 지정하지 않은 키의 입체 표현을 조금 단순화합니다.
- GIF는 반투명을 표현하지 못합니다. 투명 배경에는 APNG를 쓰세요.
