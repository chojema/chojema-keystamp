# Chojema KeyStamp v0.3.0

한국어 | [English](v0.3.0.en.md)

전체 키보드의 2D 보기와 정보 메뉴를 추가했습니다.

## 바뀐 점

- **전체 키보드 2D 보기:** ‘키보드 → 보기 → 전체 → 표현 → 2D’에서 선명한 평면 자판을 표시합니다. 기존 입체 보기와 전환할 수 있고 선택한 보기 방식은 다음 실행에도 유지됩니다.
- **2D 이미지 내보내기:** Windows와 Mac 자판, ANSI, ISO, 한글 배열, 넘버패드, 한글 자모, 지정한 키 강조, 색상과 배경 설정을 반영해 복사하거나 저장합니다. 2D 애니메이션은 키의 색상 변화로 눌림을 표현합니다.
- **정보 메뉴:** 상단 ‘정보’에서 작성자 정보, [깃허브 저장소](https://github.com/chojema/chojema-keystamp), [Chojema App Park](https://chojema.github.io/AppPark/) 링크를 제공합니다. 링크는 기본 브라우저에서 열립니다.

## 설치

`Chojema-KeyStamp_0.3.0_x64-setup.exe`를 내려받아 실행하세요. Windows 10 이상의 64비트 환경용입니다.

## 검증

- 자동 테스트 48개와 Windows x64 빌드가 통과했습니다.
- 브라우저 미리 보기에서 2D 보기 전환, 설정 유지, PNG와 SVG 저장 및 클립보드 복사를 확인했습니다.
- 정보 창의 한국어와 영어 표시, 닫기와 Esc 키, 링크 연결 대상, 좁은 화면과 어두운 테마를 확인했습니다.

## 알려진 제한

- macOS용 설치 파일은 이번 버전에 없습니다.
- 코드 서명이 되어 있지 않아 Windows SmartScreen 경고가 나올 수 있습니다.
- Windows 앱에서 정보 링크를 클릭해 기본 브라우저가 열리는 동작과 파일 저장 대화상자는 이번 버전에서 직접 재검증하지 못했습니다.
- JIS 배열은 지원하지 않습니다. ISO Enter 키는 직사각형으로 그립니다.
- GIF는 반투명을 표현하지 못합니다. 투명 배경에는 APNG를 쓰세요.
