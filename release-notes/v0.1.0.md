# Chojema KeyStamp v0.1.0

한국어 | [English](v0.1.0.en.md)

첫 공개 버전입니다.

## 할 수 있는 일

- 단일 키와 `Ctrl + Shift + Z` 같은 키 조합의 3D 키캡 이미지 만들기
- 톱뷰, 30°, 45°, 60° 프리셋과 드래그로 각도 바꾸기
- Windows와 Mac 이미지를 함께 또는 한쪽만 보기
- SVG, PNG 저장과 클립보드 복사
- `[Ctrl]+[C]`, `⌃C` 같은 텍스트 결과 복사
- 문장에 넣기 좋은 2D 키캡 PNG 복사와 저장
- 주변 키를 테두리가 흐려진 상태로 함께 표시 (ANSI, ISO, 한글 배열)
- 알파벳과 한글 자모 함께 표시
- 키 누르는 애니메이션을 HTML, GIF, APNG로 저장

## 설치

`Chojema-KeyStamp_0.1.0_x64-setup.exe`를 내려받아 실행하세요. Windows 10 이상의 64비트 환경용입니다.

## 알려진 제한

- macOS용 설치 파일은 이번 버전에 없습니다.
- 코드 서명이 되어 있지 않아 Windows SmartScreen 경고가 나올 수 있습니다.
- `Ctrl + Alt + Del`처럼 운영체제가 먼저 처리하는 키는 직접 눌러 입력할 수 없습니다. 입력란에 글자로 적으세요.
- GIF는 반투명을 표현하지 못합니다. 투명 배경에는 APNG를 쓰세요.
- 숫자 키패드와 JIS 배열은 지원하지 않습니다. ISO Enter 키는 직사각형으로 그립니다.
- 붙여 넣은 결과의 모양은 문서 프로그램과 폰트에 따라 달라질 수 있습니다.
