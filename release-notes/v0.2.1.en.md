# Chojema KeyStamp v0.2.1

[한국어](v0.2.1.md) | English

This version replaces v0.2.0. If you use v0.2.0, please update to this version.

## Changes

- The Win key in 3D and 2D images now shows the word `Win` instead of the Windows logo.

The text result for the Win key (`⊞+[E]`) and all other features stay the same. For the full keyboard and other v0.2.0 features, see the [v0.2.0 release notes](v0.2.0.en.md).

## Install

Download and run `Chojema-KeyStamp_0.2.1_x64-setup.exe`. It is for 64-bit Windows 10 or later.

## Known limitations

- This version has no macOS installer.
- The installer is not code signed, so Windows SmartScreen may show a warning.
- The JIS layout is not supported. The ISO Enter key is drawn as a rectangle.
- GIF has no partial transparency. Use APNG for transparent backgrounds.
